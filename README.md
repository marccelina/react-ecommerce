# React.js Ecommerce
The project uses Strapi to manage content (products and orders) and React as a frontend library to build UI components. It uses Stripe for payment and EmailJS for sending emails to users.

## Prerequisites
Before you begin, you'll need the following:
- Node.js (v12.13 or later)
- Git

## Installation
To install the project, follow these steps:

1. Clone the repository:
```
git clone https://github.com/marccelina/react-ecommerce.git
```

2. Install dependencies:
```
cd shop
npm install
```

3. Start the Strapi server:
```
cd server
npm run start
```

The Strapi server should now be running at http://localhost:1337

4. In a separate terminal window, start the React app:
```
cd shop
npm start
```
The React app should now be running at http://localhost:3000
